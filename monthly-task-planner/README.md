# Monthly Task Planner

A simple, no-build web app for planning monthly goals and tracking them week by week.

## Features

- Enter your name
- Add tasks you want to achieve this month
- Check off each task for Week 1, Week 2, Week 3, and Week 4
- Delete tasks you no longer need
- Progress summary showing overall weekly check-in completion
- Data is saved in your browser (`localStorage`), so it persists between visits

## Usage

Open `index.html` in any browser — no build step or server required.
